数据 provenance 更正与重训（2026-10-16 18:00 - 19:45）
============================================================

起因：README 要求 +10 dB 精度 87.01%（≥86.5%），本机只跑到 74.99%。
经溯源确认是**数据源问题**，不是训练脚本或划分的问题。

1. 桌面 CSV 不是完整的 RML2016.10a
   C:\Users\Hao\Desktop\RadioML2016.10a\*.csv 每行 129 个字段，
   只有 I 通道（128 个采样点）+ SNR，**没有 Q 通道**。
   之前 datasets/build_rml2016_from_csv.py 生成的 canonical 文件
   按 q_mode="zero" 把 Q 整列为 0，等于把 11 类问题退化成“只有实部”。

2. 官方 Zenodo 包里的权重无法复现论文数字
   DOI 10.5281/zenodo.20579317 的 dscamcnet_best.pt（37,397 B）：
     本机数据（CSV 重建）  : +10 dB 15.35%
     DeepSig 官方 pickle    : +10 dB 26.05%
   它在两种数据上都接近 11 类随机基线（9.1%），权重结构与本地一致
   （width=24、4,961 参数），但训练数据来历不明，不能作为基线。

3. 官方数据与官方划分是自洽的
   下载 Zenodo record 18397070 的 RML2016.10a.tar.bz2
   （212,669,459 B，md5 ffedb2c24e33b826d3d0df4aa8f32c1b），
   解包得到 RML2016.10a_dict_optimized.pkl（225,292,173 B）：
     每个 (调制, SNR) cell 形状 (1000, 2, 128) float32，Q 通道非零；
     与 datasets/split_indices.npz（Zenodo 20579317 原件，md5
     bb8bc1e7c41a58fad6f08a23ae7ef76d，与本仓库文件一致）配套后，
     用仓库的 models/train.py 协议训练即可达到论文量级。

4. 本次重训（models/checkpoints/dscamcnet_best.pt 已更新）
   命令：python _official/train_fresh.py \
           --data datasets/RML2016.10a_dict.dat \
           --split datasets/split_indices.npz --epochs 100 \
           --output _official/dscamcnet_best_v2.pt
   数据 220,000 条（真 I/Q）、train 158,400 / val 17,600 / test 44,000、
   +10 dB 测试分箱 2,219 条、参数量 4,961（与论文一致）。
   结果：best val 59.31%（第 87 epoch），
         **+10 dB 测试精度 89.73%**、all-SNR 59.56%。
         （同一协议的另一次完整运行得 89.00%/59.36%，说明该数字可跨运行复现。）
   旧权重（74.99%）保留在 models/checkpoints/dscamcnet_best.legacy-csv.pt，
   上一次重训的 89.00% 权重保留在
   models/checkpoints/dscamcnet_best.prev-89.00.pt。
   旧数据（CSV 重建、Q=0）保留在
   datasets/RML2016.10a_dict.csv-built.bak.dat。

     epoch   1: 74.90%   epoch  10: 81.88%   epoch  20: 84.00%
