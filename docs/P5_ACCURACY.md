# P5-2 全量板端精度（44,000 窗口）

目的：把 locked test split 的全部 44,000 个窗口逐个送进板端自研引擎，验证
「板端 int8 推理 = ONNX QDQ 模型」在全测试集上成立，而不是只对个别样本成立。

## 方法

- 板端：`dsc_infer_run_q(int8 q[256], int8 logits[11])`，replay 模式（`'R'` + 256 B → `L,q0..q10`）。
- 输入：`L2 归一化 → q = round(x / 0.00213504443) − 4`，与训练/量化管线一致。
- 参考：onnxruntime 对同一批量化窗（反量化后喂入）逐样本推理，再按输出 scale 0.35008532 / zp 63 量化成 q。
- 判据：11 个 logits 逐位一致率、argmax 一致率、分类准确率。
- 运行：`python stm32_deployment\tools\p5_full_accuracy.py --limit 0`（19.7 分钟，UART 115200）。

## 结果（44,000/44,000 全部收到回复）

| 指标 | 板端 | 参考 (ORT) | 差异 |
|---|---|---|---|
| 分类准确率（全 SNR） | **59.2045%** | 59.2091% | −0.0046 pp（2 个样本） |
| logits 逐位一致率 | **98.80%** | — | — |
| argmax 一致率 | **99.98%** | — | — |

- 极低 SNR（−20 dB）板端与参考同为 9.05%（接近 1/11 随机），符合预期。

## 结论

- 自研引擎与 ONNX QDQ 图在全测试集上等价（argmax 一致率 99.98%，准确率差 2 个样本），
  0.979 ms 的时延不是用精度换来的。
- 逐位一致率 98.8%（而非 100%）说明仍有约 1.2% 的窗口存在 ±1 LSB 舍入差，
  来源是 C 端 `lroundf`/Q31 定点与 ONNX round-half-to-even 的差异；不影响分类。
