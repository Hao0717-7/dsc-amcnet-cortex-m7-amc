2. 解读
- 仅换随机种子，+10 dB 精度在 85.71%–89.73% 之间摆动（4.0 pp），overall 摆动 2.7 pp。
  上游 README 给出的 "seed variance ±0.23 pp" 与本机实测差一个量级；本文不据此推翻上游，
  但**任何跨论文的单点比较都应带上种子**。
- 已发布的 59.56%（FP32）/ 59.21%（INT8）/ 89.73%（+10 dB）来自 seed 42，是三个种子中
  最好的一个：相对三种子均值，overall 高 1.22 pp、+10 dB 高 1.61 pp、>=10 dB 高 1.67 pp。
  也就是说，**单 checkpoint 发布的数字偏乐观**（同一训练流程内的正常波动，不是数据泄漏：
  test 集固定且所有种子都用同一 split）。
- 三个种子的排序在 +10 dB 与 >=10 dB 上一致（42 > 2024 > 7），说明差异来自训练收敛质量
  而不是评估口径。
- 板端固件仍烧 seed 42 的 INT8 网络（已发布的 0.895/0.904 ms、59.2045%、golden 22/22
  all 不受影响）。若要发布「多种子均值」，需要为每个种子重跑 PTQ + X-CUBE-AI/引擎量化常量。
